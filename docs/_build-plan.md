# Xyvionix v2 — working build plan

Working file. Source of truth for build state so nothing depends on chat context.
Spec: `implementation_prompt.md`. Visual source: `Xyvionix — frozen theme v1.0.html`.

## Working rule

Analyze → scaffold files on disk → fill content one file at a time, small writes.

## Stack decisions

| Area | Decision | Reason |
|---|---|---|
| Framework | Astro 7.x (latest stable on npm, 2026-09-27), static output | Spec §18 |
| Styling | Plain CSS + design tokens, no Tailwind | Theme uses a small utility set; tokens are cleaner, no CDN |
| Fonts | Self-hosted Instrument Sans + JetBrains Mono (OFL, via fontsource) | Spec §52 |
| Content | Astro content collections, Markdown + typed frontmatter | Spec §19 |
| Routing | `src/pages/[slug].astro` over all collections, flat root URLs | Spec §5, §20 |
| URL form | No trailing slash, `build.format: 'file'`, https://xyvionix.com | Spec §24 |
| OG images | Build-time 1200x630 PNG per page (satori + resvg) | Spec §34 |
| Sitemap | `@astrojs/sitemap` | Spec §25 |
| RSS | `@astrojs/rss` at `/rss.xml` | Spec §39 |
| Search | Static JSON index + small vanilla JS at `/search` | Spec §56, CSP-clean |
| JS | External scripts only, no inline, no framework | Strict CSP, Spec §52/§67 |
| Tests | `node --test` for slug/route rules | Spec §20 |
| Hosting | Provider-neutral: `_headers`, `_redirects`, `vercel.json` | Spec §66 |

## Theme tokens extracted

Dark (obsidian): bg0 #0C0C0B, bg1 #121211, bg2 #181816, tx #F5F4F1, mut #A8A7A0,
fnt #6E6D66, gst #4A4944, ln rgba(245,244,241,.08), ln2 rgba(245,244,241,.16).

Light (off-white): bg0 #FAFAF8, bg1 #F1F1EE, bg2 #E9E9E4, tx #171715, mut #55544D,
fnt #8B8A82, gst #CFCEC6, ln rgba(23,23,21,.1), ln2 rgba(23,23,21,.22).

- Shell max-width 82rem; gutters 20 / 32 / 48px.
- Section padding 80 / 112 / 144px (mobile / sm / lg).
- Radius 2px default, 8px nav, 12px glass panels.
- Display type: weight 600, tracking -0.035em. H2 1.85 / 2.4 / 3rem.
- Label: JetBrains Mono 11px, tracking .12em, uppercase, dashed 24px lead rule.
- State marks 12px: assured solid, degrading 45deg stripes, at-risk hollow, unassured dashed.
- Motion: reveal 16px rise .9s, line draw 1.8s, arrow nudge 4px. Reduced-motion honoured.
- Rhythm: dark hero → mono band → light sections alternating bg0/bg1 → dark CTA → dark footer.
